## What is implemented

Quick take and Breakdown keep their frames, labels, order and result card.
Complete accepted prose travels through the closed, versioned
`result_readout_content` envelope, stamped with its requested creation language.
The reader requires a matching version, surface and current workspace language.
Older saved readouts, mismatches, invalid envelopes and failed compositions use
today's localized templates. Reads neither call a model nor rewrite history.
A newly requested Breakdown on an older run is composed now in the current
language and saved as a new message.

Both composers receive full stored metrics and canonical execution inputs,
plus the actual chart when one was saved. The same owner checks figures/units,
benchmark direction and internal field names. Required mentions, fact-ID
self-reports and content caps are removed. Prompt instructions assign short
first-glance interpretation to Quick take and deeper complementary content to
Breakdown. Tiers remain chat and context.
