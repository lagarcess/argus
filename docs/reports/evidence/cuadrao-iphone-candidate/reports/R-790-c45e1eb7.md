## Findings

### P2-1: the tap-target check misses buttons under a container-level plain style, and one live dead area is hidden that way

- `ios/DesignPreviewTests/run_tap_targets.py:28-33`: the check walks back from each `buttonStyle(.plain)` line to the
  nearest `Button`/`NavigationLink` and passes if any line in that window has `contentShape`. When the style sits on a
  container, only the last control in the container is read.
- Live miss: `ios/ArgusFoundation/Cuadrao/CuadraoVoiceMessagePanel.swift:104-105` has
  `Button(es ? "Cancelar" : "Cancel", role: .destructive) { … }.frame(minWidth: 80, minHeight: 48)`. The frame sits
  outside the button and the plain style comes from the container at :114. Only the "Cancelar" glyphs take taps. The
  rest of the 80x48 target is dead, which is the class this PR says it closes. Reviewed entry `6e1228b1526b`
  (`tap_targets_reviewed.txt:31`, "filled capsule") is true for Stop only, but its window is the whole container.
  Cancel never appears in the before or after audits.
- Mutation evidence (scratch copy): removing `.contentShape` from the VoiceBar mute label, or from the
  OrderedCollection Edit label, still reports `unreviewed: 0` and exits 0. Adding a new standalone plain Button with no
  shape is caught (`UNREVIEWED`, exit 1).
- Brace-matching every style line finds exactly four container-styled sites: LiveVoice header (:70-91), OrderedCollection
  (:47-51), VoiceBar (:20-42), VoiceMessagePanel (:103-114). Only VoiceMessagePanel has a live dead area today.
- Smallest fix:
  1. Put Cancel in label form, which keeps the same layout:
     `Button(role: .destructive) { message.cancel() } label: { Text(es ? "Cancelar" : "Cancel").frame(minWidth: 80, minHeight: 48).contentShape(Rectangle()) }`,
     with `.fixedSize` and the identifier kept on the button.
  2. Either move `.buttonStyle(.plain)` from those four containers onto each button, which renders the same and lets
     the check read each control, or make the check fail when a style line's brace-matched opener is not a
     Button/NavigationLink/label.

### P3-1: reviews that rely on a helper's shape are not tied to that helper

- `run_tap_targets.py:33` hashes only the call-site window. About 26 of the 42 entries say "X carries the shape".
  Deleting `.contentShape(Rectangle())` from `FinancialActivityRow` (`Accounts/AccountActivityView.swift:179`) leaves

  `struct <Name>` or `func <name>(` body contains `contentShape`. Alternatively, put the helper body into the digest.

### P3-2: the split member toggle changes layout (more room for long names, smaller dead zone before the share field)

- `Cuadrao/Planning/CuadraoGroupExpenseEditor.swift:77`: the label now fills the row, and the `Spacer()` that sat
  between the label and the trailing amount or share field is gone.
- Old minimum gap: 12 + Spacer default minimum (8) + 12 = 32 pt. New gap: 12 pt. So:

  32 pt gap and the old truncation point. The rest of the row stays tappable.
