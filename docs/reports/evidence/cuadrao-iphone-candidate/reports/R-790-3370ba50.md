### 3. Money input (`00b5be65`, `Cuadrao/CanvasDecimalInput.swift`)

Reach: all six call sites are under `ios/ArgusFoundation/Cuadrao/` (design preview). Nothing in
`Connected/` uses it, so no release user reaches this code.

Mechanism (`:60-63`, `:73-75`, `:106-107`, `:136-144`): the coordinator owns the unformatted text;
each binding write is queued on the main queue; `updateUIView` rewrites the field only when no
write is queued and the binding differs from the coordinator's value.

- Order: writes are queued FIFO from one thread, so they cannot reorder among themselves; error
  and value travel in the same block (`:107`).
- Last keystroke on fast submit: the block runs on the next main-queue drain, before a later touch
  event. The committed journey types "1250.5" in one burst then taps Done
  (`CuadraoConsistencyUITests.swift:13-16`); the author's log shows it failing before and passing
  after.
- Focus change: `textFieldDidEndEditing` (`:125-134`) formats from the coordinator's value and
  queues behind any keystroke write, so the formatted value lands last.
- External model change (edit an existing amount, clear, recomputed share): with nothing queued,
  `:60-63` adopts the binding and rewrites the field. First render of an existing amount works
  because the coordinator starts at "" (`:73`).
- Currency change: `updateUIView` never reformatted on currency change before either; unchanged.
- View gone: the queued block writes to a `@State`-backed binding of a removed view, which is a
  no-op. Every caller binds `raw` to `@State` (`CanvasMoneyValueInput.swift:14`,
  `CuadraoAccountCanvas.swift:121`, first-account sheet, gallery).
- Paste and locales: the validation paths are unchanged apart from routing the error through the
  queue. es-419, es_DO and en use a period, so the pad matches. Not changed by this diff and
  preview only: in a comma-decimal region the pad's "," is stripped silently at `:93`.

Residual, no caller hits it today: a queued write can land after an external write made in the
same main-queue turn (for example an action that resigns focus and clears the amount in one
closure). I checked the one same-turn site, `CuadraoAccountCanvas.swift:173-174`; it resigns and
flips `reviewing`, and does not write the amount. Keep that invariant if a caller ever resets the
amount in the same action as dismissing the keyboard.
